# Evidence — requirement coverage map

Each folder is a real run kept as proof of one capability/outcome. Trimmed to the essential coverage set;
older iteration runs were removed. Discovery evidence is credential-redacted (`[REDACTED]`); throwaway
sandbox usernames (`itfai_*`) are left per the documented posture (REPORT §7).

**Where to start (the brief's §6.3 shape — an artifact plus a discovery-run log and a replay-run log):** the real
LLM-driven **discovery** run is `discovery_request_loan_20260825_001738/`; a clean **deterministic replay** is
`phaseB_ci_run_test1_20260824_234435/`; and the **error / exceptional-state** result is
`lookup_checking_balance_replay_20260827_051820/` (a missing account handled as a business outcome, not a crash).
The remaining rows cover escalation, cross-tenant, mutating, and finding-v cases.
